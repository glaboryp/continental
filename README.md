# Continental

Marcador para partidas del juego de cartas Continental, pensado para un
único móvil/tablet compartido en la mesa. Sin backend: el estado de la
partida se guarda en el navegador (`localStorage`).

## Desarrollo

```bash
npm install
npm run dev
```

## Tests

```bash
npm run test
```

## Build de producción

```bash
npm run build
npm run preview
```
